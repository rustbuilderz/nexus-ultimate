Nexus Ultimate is a desktop control panel for managing your operator movement profiles quickly and clearly.
When you open the app, you get a main dashboard where you can turn the script on/off, adjust core movement sliders (Down Force, Left/Right Force, Delay Time), set keybinds, and choose a visual theme. It is built so you can make live adjustments without digging through config files.

To use operator-specific settings, open the Config selection menu and pick a BMP/operator tile from the grid. The app loads that operator’s values from your saved profile data, shows the active settings, and lets you update them using the main controls. After adjusting, click Save to ops.json to store the changes for that operator. You can also filter operators by team type, switch profiles quickly, and keep everything organized in one place.

Key Features
Per-operator profile loading and saving
Live movement controls (vertical force, horizontal force, delay)
Custom keybinds for toggling script/console and reloading settings
Theme selector and polished custom UI
Local persistence for profiles, keybinds, and UI settings
Dedicated configuration window for faster profile editing
